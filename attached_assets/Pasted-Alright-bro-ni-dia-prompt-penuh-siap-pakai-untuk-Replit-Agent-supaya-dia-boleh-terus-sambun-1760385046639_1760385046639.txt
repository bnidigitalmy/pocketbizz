## 🧠 **REPLIT AGENT PROMPT – MANISBIZZ EXPANSION (DESSERT VENDOR SYSTEM)**

> ⚙️ **Objective:**
> Extend the current PocketBizz-based app (ManisBizz.zip) into a complete dessert vendor management system.
> The app should help Malaysian home bakers manage daily production, delivery, claim tracking, and profit/loss — without manual calculations.

---

### 🗂️ **PROJECT OVERVIEW**

**Base:** PocketBizz system (React + Supabase or LocalStorage PWA)
**Brand:** ManisBizz 🍰
**Theme:** Soft pink + cream + cocoa brown (dessert pastel style)
**Font:** Poppins or Quicksand
**Target user:** Home-based baker who sends desserts daily to vendor shops.

---

## 🧩 **TASK: ADD 6 NEW MODULES**

---

### 1️⃣ `modules/delivery.html` – **Vendor Delivery Tracker**

**Purpose:** Record daily deliveries for each vendor.

**Features:**

* Form: vendor, product, quantity, delivery date, price, status (`delivered`, `pending`, `rejected`)
* Auto-calculate total value = quantity × price
* Auto deduct from product stock
* Button “Duplicate Yesterday” → auto-fill from last delivery data
* Save data to `localStorage.pocketbizz_delivery`

**Table fields:**

```json
{
  "id": "del_001",
  "vendor_id": "v001",
  "product_id": "p001",
  "quantity": 20,
  "price": 5,
  "status": "delivered",
  "date": "2025-10-14"
}
```

---

### 2️⃣ `modules/claim-report.html` – **Vendor Claim & Settlement Report**

**Purpose:** Track vendor payments and pending claims.

**Features:**

* Display table by vendor: total delivered, total claimed, balance
* Toggle claim status (`paid` / `pending`)
* Filter by week / month
* Summary box: total sales, total pending claim, total received
* Save to `localStorage.pocketbizz_claims`

**Table fields:**

```json
{
  "vendor_id": "v001",
  "total_sales": 250,
  "total_claimed": 200,
  "pending_balance": 50,
  "last_payment_date": "2025-10-13"
}
```

---

### 3️⃣ `modules/expired-products.html` – **Expired & Rejected Tracker**

**Purpose:** Track expired or rejected desserts and adjust profit accordingly.

**Features:**

* Field: product, batch_no, expiry_date, rejected_qty, reason
* Auto alert if expiry date < today
* Auto deduct rejected items from profit
* Optional: “Mark as disposed” button

**Save to:** `localStorage.pocketbizz_expired`

---

### 4️⃣ `modules/daily-summary.html` – **Daily/Midweek Profit & Loss Summary**

**Purpose:** Summarize sales, expenses, and profit automatically.

**Features:**

* Date range filter (daily, weekly, monthly)
* Auto calculate:

  * Total Sales = sum(sales)
  * Total Expenses = sum(expenses)
  * Rejected Loss = sum(expired)
  * Profit = Sales - (Expenses + Rejected Loss)
* Show 3 cards:

  * 💰 Profit today
  * 📦 Total sales
  * 💸 Total expenses
* Export as PDF / CSV

**Save to:** `localStorage.pocketbizz_summary`

---

### 5️⃣ `modules/notification.js` – **Smart Reminder System**

**Purpose:** Notify user about vendor claim delays & near-expiry products.

**Logic:**

* Run on app open or daily check (using `setInterval` or `serviceWorker`)
* Scan `pocketbizz_claims` & `pocketbizz_expired`
* If vendor pending > 3 days → alert
* If product expiry < 1 day → alert

**Use:** PWA Notification API (or `alert()` fallback)

```js
new Notification("Reminder: Vendor Kak Ani belum claim 3 hari!");
```
