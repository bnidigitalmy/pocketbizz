# 🧾 **Upgrade: Smart Supplier Order (Customizable PO System)**

> *“App bantu owner detect stok nak habis, tapi bagi kebebasan penuh nak ubah senarai & kuantiti sebelum buat pesanan.”*

---

## 🎯 **Objektif Upgrade**

* Auto detect bahan low-stock
* Tapi user boleh **edit, tambah, buang, dan ubah kuantiti** sebelum generate WhatsApp order / PDF PO
* Semua PO disimpan untuk rekod dan laporan perbelanjaan

---

## 🧱 **Fungsi Lengkap (Smart Supplier Order v2.0)**

| Fungsi                              | Keterangan                                                                  | Status |
| ----------------------------------- | --------------------------------------------------------------------------- | ------ |
| 🧮 **Auto Generate Order List**     | Sistem semak bahan mentah low-stock (contoh <2kg) dan sediakan senarai auto | ✅      |
| ✏️ **Editable List (Dynamic Form)** | User boleh tambah / padam / edit item, kuantiti, supplier sebelum hantar    | 🆕     |
| 🧾 **Manual Add Item**              | Kalau nak beli bahan baru yang belum ada dalam stok                         | 🆕     |
| 📦 **Supplier Selection**           | Pilih supplier dari senarai vendor                                          | ✅      |
| 💬 **Generate WhatsApp Order**      | Hasilkan mesej auto (editable) dan terus buka WhatsApp                      | ✅      |
| 📄 **Generate PDF PO**              | Simpan versi rasmi untuk audit / bukti perbelanjaan                         | ✅      |
| 💸 **Add to Expenses**              | Bila tandakan “Barang Diterima”, sistem auto tambah ke laporan modal        | ✅      |
| 🔁 **Repeat Order**                 | Boleh reorder dari pesanan lama                                             | 🆕     |

## 🧮 **Contoh Flow Logik (Step-by-Step)**

### **Step 1: Buka menu “Order Barang”**

App akan auto scan bahan low-stock → paparkan hasil carian:

```
🍫 Cocoa Powder – 1.2kg left (Low)
🧈 Butter – 0.8kg left (Low)
🥚 Egg – 3 papan left (Low)
```

> “3 bahan low-stock dijumpai. Nak semak semua atau pilih manual?”

---

### **Step 2: Editable Order List muncul**

User boleh ubah terus atas interface:

| Item                 | Unit  | Qty (Auto) | Edit | Delete |
| -------------------- | ----- | ---------- | ---- | ------ |
| Butter               | kg    | 5          | ✏️   | ❌      |
| Cocoa Powder         | kg    | 2          | ✏️   | ❌      |
| Egg                  | papan | 10         | ✏️   | ❌      |
| [+ Tambah Item Baru] |       |            |      |        |

---

### **Step 3: Pilih Supplier**

Dropdown:

```
Select Supplier:
🧈 Butter King Enterprise
🍫 BahanBaker Sdn Bhd
🥚 Pasar Fresh Mart
```

Boleh pilih 1 supplier untuk semua barang, atau assign supplier individu (multi-supplier order list 🔥 optional feature).

---

### **Step 4: Generate WhatsApp / PDF**

Dua butang:

* 📱 **WhatsApp Order**
* 🧾 **Generate PO PDF**

---

#### 💬 WhatsApp Message Auto Template:

```
Hai Butter King Enterprise 👋
Saya nak buat pesanan berikut:

🧈 Butter 5kg
🍫 Cocoa Powder 2kg
🥚 Egg 10 papan

Tolong confirm stok & harga ya.
– Dapur Manis Bakery 🍰
```

💡 *User boleh preview & ubah mesej sebelum dihantar.*

---

### **Step 5: Barang Sampai → Mark as Received**

Bila tanda ✔️ “Barang Diterima”:

* Auto tambah stok bahan mentah
* Auto rekod ke “Perbelanjaan”
  (Kategori: Bahan Mentah – RMxxx)
* Auto update laporan tunai

## ⚙️ **Automasi Tambahan (Smart AI Flow)**

| Trigger                         | Auto Action                                |
| ------------------------------- | ------------------------------------------ |
| Stok bahan < threshold          | Tambah ke “Draft Order” list               |
| PO dihantar                     | Status: “Pending Delivery”                 |
| Barang diterima                 | Tambah ke laporan modal + update stok      |
| Supplier repeat order           | Simpan pattern (untuk AI suggest re-order) |
| Banyak bahan low-stock serentak | AI akan cadang “Bulk Restock Mode”         |
