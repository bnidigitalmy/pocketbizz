## 🎯 Domain Architecture

```
www.pocketbizz.my → Vercel (Marketing Site)
pocketbizz.my → Redirect to www (301)
app.pocketbizz.my → Railway (Application)
```

## 📋 Step-by-Step Setup

### **STEP 1: Add WWW Domain to Vercel**

1. **Go to Vercel Dashboard:**
   - URL: https://vercel.com/dashboard
   - Select `pocketbizz-marketing` project
   - Click **Settings** → **Domains**

2. **Add Primary Domain:**
   - Click **"Add"** button
   - Enter: `www.pocketbizz.my`
   - Click **"Add"**

3. **Expected Message:**
   ```
   Invalid Configuration
   
   Please add a CNAME record with your DNS provider:
   Type: CNAME
   Name: www
   Value: cname.vercel-dns.com
   ```

4. **Keep this tab open** - you'll need this info!

---

### **STEP 2: Add Naked Domain to Vercel**

1. **In same Vercel Domains page:**
   - Click **"Add"** again
   - Enter: `pocketbizz.my` (without www)
   - Click **"Add"**

2. **Expected Message:**
   ```
   Invalid Configuration
   
   Please add an A record with your DNS provider:
   Type: A
   Name: @ (or leave blank)
   Value: 76.76.21.21
   ```

3. **Or may suggest CNAME:**
   ```
   Type: CNAME
   Name: @
   Value: cname.vercel-dns.com
   ```

4. **Enable Redirect (Important!):**
   - After adding both domains
   - Find `pocketbizz.my` in list
   - Click **⋮ (three dots)** → **"Redirect to www.pocketbizz.my"**
   - Select **"Permanent (308)"** or **"Permanent (301)"**
   - Click **"Redirect"**

---

### **STEP 3: Configure Shinjiru DNS**

1. **Login to Shinjiru:**
   - URL: https://client.shinjiru.com.my (or your panel)
   - Navigate to **"Domains"** → Select `pocketbizz.my`
   - Click **"Manage DNS"** or **"DNS Management"**

2. **Add WWW CNAME Record:**
   ```
   Type: CNAME
   Host/Name: www
   Points to/Value: cname.vercel-dns.com
   TTL: 3600 (default) or 14400
   ```
   - Click **"Add Record"** or **"Save"**

3. **Add Root Domain (Choose ONE method):**

   **Option A: CNAME (Recommended if supported):**
   ```
   Type: CNAME
   Host/Name: @ (or leave blank for root)
   Points to/Value: cname.vercel-dns.com
   TTL: 3600
   ```

   **Option B: A Record (If CNAME not supported for root):**
   ```
   Type: A
   Host/Name: @ (or leave blank)
   Points to/Value: 76.76.21.21
   TTL: 3600
   ```
   - **Note:** Check Vercel dashboard for exact IP address

4. **Save Changes** and wait for propagation (5-30 minutes)

---

### **STEP 4: Add App Domain to Railway**

1. **Go to Railway Dashboard:**
   - URL: https://railway.app/dashboard
   - Select your `PocketBizz` project
   - Click **Settings** tab

2. **Add Custom Domain:**
   - Scroll to **"Networking"** → **"Domains"** section
   - Click **"+ Custom Domain"**
   - Enter: `app.pocketbizz.my`
   - Click **"Add"**

3. **Copy CNAME Value:**
   - Railway will show:
   ```
   Add this CNAME record to your DNS provider:
   Name: app
   Value: pocketbizz-production-f02a.up.railway.app
   ```
   - **Copy the exact value** (your deployment URL)

---

### **STEP 5: Add App Domain to Shinjiru DNS**

1. **Back to Shinjiru DNS Management:**
   - Same panel as Step 3

2. **Add App CNAME Record:**
   ```
   Type: CNAME
   Host/Name: app
   Points to/Value: <Railway CNAME from Step 4>
   TTL: 3600
   ```
   - Example: `pocketbizz-production-f02a.up.railway.app`
   - Click **"Add Record"** or **"Save"**

## 🐛 Troubleshooting

### **Problem: "Invalid Configuration" in Vercel**
**Solution:** 
- Wait 10-30 minutes for DNS propagation
- Clear browser cache
- Try incognito mode
- Check DNS with `nslookup`

### **Problem: SSL Certificate Error**
**Solution:**
- Wait 15 minutes after DNS propagation
- Vercel/Railway auto-generate certificates
- Check domain status in dashboards
- May take up to 24 hours max

### **Problem: "This site can't be reached"**
**Solution:**
- Verify DNS records in Shinjiru
- Check CNAME values are exact (no trailing dots)
- Wait for propagation
- Test with `nslookup`

### **Problem: Railway domain not working**
**Solution:**
- Verify CNAME points to correct Railway URL
- Check Railway deployment is running
- Railway may take 10-15 min to provision SSL
- Check Railway logs for errors
